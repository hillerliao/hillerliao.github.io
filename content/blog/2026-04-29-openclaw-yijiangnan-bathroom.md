孩子这周学了白居易的《忆江南》。

按照以前的经验，刚学完几天还记着，但过不了多久就会忘干净。要是专门提醒他背，又容易变成任务，反而让他更抵触。

我突然想到一个地方：**卫生间**。

每天早晚刷牙，他都会站在那里两三分钟。这个时间不长，但足够看见几个字。如果我放在卫生间那块电子墨水屏上，正好显示着“忆江南”三个字，是不是就能顺手提醒他想起这首诗？

不是逼他背，也不是增加一个学习任务，只是在一个每天都会经过的地方，轻轻贴一个提醒。

于是我对 **OpenClaw（本地智能体）** 说了一句：

> “把忆江南这三个简体汉字发成图片推送到卫生间的那一块墨水屏幕，字尽可能大一点，不能太小，只要把屏幕四边留点空白就行。”

几分钟后，卫生间的电子墨水屏上就**贴**上了三个大字：

**忆江南**

白底黑字，居中，挺大，四边留了一点空白。

这件事本身不复杂，有意思的地方在于：OpenClaw 这类智能体不只是“会聊天”，而且可以把一句很日常的话，变成现实世界里的一个动作。

## 这块小屏幕，为什么能被 OpenClaw 控制？

这里需要解释一下这块屏幕。

我用的是 **MindReset Dot** 一类的电子墨水屏。你可以先把它理解成一个“小型 Kindle 屏幕”，它不刺眼，功耗很低，内容刷新之后可以长时间停留在那里。

但它和 Kindle 最大的区别是：Kindle 是拿在手里读书的，MindReset 这种屏幕更像是**贴**在家里某个固定位置的“信息牌”。

比如：

- 贴在冰箱上，显示今天要买什么；
- 贴在玄关，显示出门前要带的东西；
- 贴在书桌，显示今天最重要的一件事；
- 贴在卫生间，显示孩子本周要背的诗。

如果只是一个普通电子相框，其实也没什么特别。你手动换图，它就显示一张图。

**MindReset 这类设备真正有魅力的地方在于：它能联网，而且有开放 API。**

这意味着它不是一个孤立的屏幕，而是一个可以被外部程序控制的显示节点。

对普通用户来说，这可能只是“我可以远程换屏幕内容”。

但对 **OpenClaw** 这类智能体来说，这就是一个入口。它可以根据你的指令，自动生成内容，再调用 API，把内容**贴**到指定屏幕上。

所以，这块屏幕不是一个“死”的硬件。

它是家里一个可以被 OpenClaw 更新的信息角落。

## 为什么提醒背诗，我反而选了卫生间？

孩子背诗，最自然的地方当然是书桌。

但我这次反而选了卫生间。

原因很简单：刷牙是一个非常稳定的日常动作。每天早晚都会发生，而且每次都有两三分钟的空档。

这个时间不适合塞进复杂学习任务，但很适合放一个轻量提醒。

比如看到“忆江南”三个字，他可能就会自然想起：

> 江南好，风景旧曾谙。  
> 日出江花红胜火，春来江水绿如蓝。  
> 能不忆江南？

这不是正式背诵，也不是考试。

它更像是把课堂里刚学到的东西，轻轻**贴**回生活里。

这也是电子墨水屏很适合的地方。

手机提醒太强了。它会震动，会弹窗，会把人拉进另一个信息流。孩子看到手机，也很容易被别的东西吸引。

纸条又太弱了。贴上去几天之后，就很容易变成背景，大家都看不见了。

电子墨水屏刚好在中间。

它不吵，不亮，不抢注意力，但它一直在那里。

你路过，就能看到。

## OpenClaw 做的，不是回答，而是执行

如果只是让聊天机器人回答问题，它最多会告诉你：

> “你可以用 Python 生成一张图片，然后调用电子墨水屏的 API 推送过去。”

但 OpenClaw 不是停在“告诉你怎么做”。

这一次，它实际完成了这些步骤：

1. 找到卫生间那块屏幕对应的设备别名 `toilet`。
2. 解析出真实设备 比如ID：`48F6EE576429`。
3. 按屏幕尺寸（296×152 px）生成一张黑白图片。
4. 找到系统里能显示中文的字体（文泉驿正黑）。
5. 把「忆江南」三个字放到尽可能大。
6. 保留四边空白。
7. 调用 MindReset 的图片 API，把图片**贴**到屏幕上。
8. 再通过飞书把原图发回来给我确认。

这些步骤如果人工做，当然也可以。

你可以打开设计软件，建一个 296×152 像素的画布，选中文字体，调整字号，导出 PNG，再打开设备后台或者写 curl 请求，把图片推送过去。

但重点是：**这次我没有做这些操作。**

我只是用自然语言描述了我要的结果。

OpenClaw 把这句话拆成了可以执行的步骤，并且真的执行了。

这就是我觉得这类工具开始变得有用的地方。它不是又一个问答窗口，而是一个可以调用工具、读写文件、生成图片、访问 API、控制设备的本地智能体。

## 有些提醒，不适合出现在手机里

我们平时说“提醒”，很容易想到手机通知。

但手机通知适合的是即时信息，比如快递到了、会议快开始了、有人发消息了。

《忆江南》这种内容不是即时通知。它不需要震动，也不需要弹窗。它只需要在某个固定地方安静地出现，让人每天多看几次。

这就是墨水屏的价值。

| 手机提醒 | OpenClaw + MindReset 墨水屏 |
|---|---|
| 会打断当前动作 | 不打断，只是安静显示 |
| 很快消失 | 一直停留在那里 |
| 容易引导人继续刷手机 | 只显示一件事 |
| 适合即时消息 | 适合长期提醒 |
| 信息在 App 里 | 信息**贴**在真实空间里 |
| 需要主动打开或查看 | 路过就能看到 |

所以，我不觉得这是一个“酷炫硬件玩法”。

它更像是一种家庭信息摆放方式的变化。

以前我们把信息放在手机里、App 里、群聊里、备忘录里。

现在，我们可以让 OpenClaw 把一部分信息**贴**回家里的空间里。

## 从一首诗开始，家里还能**贴**哪些“轻提醒”？

如果你家里也有类似的联网电子墨水屏，或者你正在考虑买一块，最值得尝试的不是复杂自动化，而是从很小的家庭提醒开始。

尤其是那些“重要，但不紧急”的信息。

比如孩子本周刚学的古诗。

如果每天只是在书桌前背，孩子会觉得这是学习任务。但如果它出现在刷牙、吃饭、出门这些生活场景里，压力会低很多。

下面这些玩法都可以从同一个思路扩展出来。

### 1. 本周古诗
卫生间显示诗名，饭桌旁显示一句诗，书桌旁显示完整诗文。

比如卫生间只显示：
```
忆江南
```
或者只显示最容易忘的一句：
```
春来江水绿如蓝
```

### 2. 每日英语单词
每天一个单词，配一句很短的例句。
```
remember
记得，想起
```
刷牙时看一眼，比专门打开背单词 App 轻很多。

### 3. 乘法口诀
如果孩子最近在练某一组乘法口诀，可以只显示当天的一条。
```
7 × 8 = 56
```
不要一次显示太多。墨水屏最适合少量、稳定、反复出现的信息。

### 4. 成语提醒
每天一个成语，晚上吃饭时让孩子讲讲意思。
```
画蛇添足
```
这比直接塞给孩子一整页成语表更自然。

### 5. 出门清单
贴在玄关：
```
水杯
作业
红领巾
```
这个适合早上出门前看一眼。

### 6. 睡前问题
放在床头：
```
今天最开心的事？
```
不是学习任务，而是引导孩子做一点表达和回顾。

### 7. 家庭共读
如果本周全家一起读一本书，可以每天显示一句摘录。
```
今天读第 3 章
```

### 8. 低压力错题提醒
不要显示“你又错了”。
只显示一个关键词，让孩子自己回想。

比如数学里容易错的是“单位换算”，屏幕上就只显示：
```
单位
```
提醒越轻，越容易长期存在。

## 普通人不需要懂 API，只需要知道这三层

如果你关心怎么入手，可以把这套东西拆成三层。

**第一层是硬件**：一块可以联网、有开放 API 的电子墨水屏，比如 MindReset Dot。

**第二层是智能体**：OpenClaw 或 Hermes Agent 这类工具，能理解你的自然语言指令，也能调用本地脚本和网络 API。

**第三层是场景**：孩子背诗、出门提醒、家庭共读、每日单词、错题复习。

真正有价值的是三层连起来。

如果只有屏幕，它只是一个可以显示东西的硬件。

如果只有 OpenClaw，它还停留在电脑里或者聊天窗口里。

但当 OpenClaw 能控制这块屏幕时，事情就变了。

你的家里多了一个可以被自然语言更新的信息位置。

## 背后其实很简单：一句话变成一张图，再**贴**到屏幕上

如果你关心技术，背后其实并不神秘。

这次任务大致是这样完成的：

```
自然语言指令
→ OpenClaw 理解目标
→ 找到卫生间屏幕设备 ID
→ 生成 296×152 黑白 PNG 图片
→ 用中文字体渲染「忆江南」
→ 转成适合设备的图片格式
→ 调用 MindReset 图片 API
→ **贴**到电子墨水屏
```

一些实际参数是：

```
屏幕尺寸：296 × 152 px
图片格式：黑白 PNG
生成工具：Python Pillow
中文字体：文泉驿正黑
设备别名：toilet
推送方式：MindReset 图片 API
```

这些技术细节对普通用户来说不用记。

关键是，OpenClaw 可以把这些步骤封装起来。下一次我不需要再关心图片尺寸、字体路径、base64 编码、API 请求格式。

我只需要说：

> “把这周的古诗**贴**到卫生间屏幕。字大一点。只显示诗名。”

或者：

> “明天开始，每天早上把一个英语单词**贴**到玄关屏幕上。”

这才是实操价值。

## 这不是把家变成补习班

我知道有人看到这里，可能会担心：这是不是又在给孩子增加学习压力？

我反而觉得，好的用法应该是相反的。

**不要把屏幕塞满学习内容。**

**不要每天推一大堆任务。**

**不要让孩子一刷牙就看到密密麻麻的知识点。**

这块屏幕最适合的是：**少量、温和、稳定、低压力**。

比如这次只显示三个字：

**忆江南**

它不是完整课文，也不是背诵要求。

它只是一个入口。

孩子看到它，可能会想起老师这周讲过的诗，可能会顺口念一句，也可能只是多看一眼。

这就够了。

学习不一定总是正襟危坐地发生。有时候，生活里的轻提醒，反而更容易留下痕迹。

## 当信息从手机里走出来

过去几年，我们把越来越多的信息塞进手机。

日程在手机里，备忘在手机里，孩子作业在群里，家庭提醒也在群里。

结果是：什么都在手机里，最后什么都容易被信息流淹没。

电子墨水屏提供了一个反方向的可能。

它把一小部分信息从手机里拿出来，**贴**回真实空间。

而 OpenClaw 这类智能体，让这件事变得更灵活。

你不用每次打开 App 去改内容，也不用手动上传图片。你只要用一句自然语言告诉它，你想让哪个角落显示什么。

卫生间可以显示本周古诗。

玄关可以显示出门清单。

冰箱可以显示今天晚饭安排。

书桌可以显示今天最重要的一件事。

这些都不是大场面，但很真实。
